# Changelog

## 1.0.0 - 2026-07-29

The first production release of KodeView.

### Highlights

- Download and update public GitHub repositories for offline reading
- Browse large repositories with a searchable, virtualized file tree
- Read syntax-highlighted source with find, selection, copy, and share tools
- Preview Markdown and open its links
- Protect optional GitHub tokens with device-backed secure storage
- Preserve the last working repository copy when a sync fails
- Improve startup, loading, empty, error, and storage-management states
- Support system, light, and dark themes throughout the app
